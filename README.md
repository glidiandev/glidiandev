### Hi, I'm Glidian 👋

I build interfaces I'd actually want to use: small, fast, and a little cinematic.

A neon home screen for Android TV. Big glowing app tiles, a music bar that shows what's playing, and it works offline. [Try it in your browser](https://glidian.dev/home-deck/demo/).
